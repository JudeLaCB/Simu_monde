# Monde VJ — Interface simplifiée (Couche 17)

Ouvrir [le prototype HTML](Monde_VJ_Atlas_3D_Couche_17_Interface_Simplifiee.html) dans Chrome ou Edge.

**Mode simple :** choisir parmi les 6 paysages, saisir une seed, cliquer sur **Générer le monde**. Les réglages avancés des couches précédentes sont conservés dans un menu déroulant.

- Mixte : relief varié, bassins et rivières
- Montagnes : crêtes alpines prononcées
- Bord de mer : basses côtes connectées au bord du domaine ; **mer simplifiée en bassin fermé**
- Plateaux : reliefs élevés et canyons
- Collines : relief plus doux
- Vallées et lacs : bassins et reliefs intermédiaires

Les paramètres avancés peuvent être personnalisés, puis appliqués avec leur bouton Régénérer. Le bouton principal réinitialise d'abord les valeurs du profil. Seed identique et profil identique => résultat identique.

**Conservé :** météo dynamique, rivières, géomorphologie, pluie occultée, nappes phréatiques, 2 000 pas/jour, faune en pause. Voir [PROGRESS.md](PROGRESS.md) pour le périmètre et les tests.
