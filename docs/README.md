# Documentation — Simu_monde

## Reprise rapide d'une session

Lire dans cet ordre :

1. [AGENTS.md](../AGENTS.md)
2. [État courant / handoff](project_handoff_report.md)
3. la spec ou l'issue active
4. le code et les tests concernés

Lire ensuite, seulement si nécessaire :

- [Architecture](architecture.md)
- [Principes de simulation](simulation_principles.md)
- [Roadmap](roadmap.md)
- [Workflow de développement](development_workflow.md)

## Répartition de l'information

- **AGENTS.md** : règles permanentes de travail IA.
- **project_handoff_report.md** : état courant compact et prochaine étape.
- **architecture.md** : frontières et responsabilités du système.
- **simulation_principles.md** : règles scientifiques/numériques durables.
- **roadmap.md** : séquençage produit.
- **development_workflow.md** : méthode de préparation, implémentation et review.
- **specs/** : contrats temporaires ou durables des changements significatifs.

GitHub live reste la source de vérité pour branches, PR, issues, CI et merges.
